# Levitate
Levitate's "thesis statement" is to be a text editor unlike any other text editor. The inspiration for Levitate came from using Google Docs one day, and wishing I could just click anywhere on the page and start typing where I clicked. Then, I thought to myself *well... why can't I?* and came to the conclusion: "because nobody who's made a text editor has ever had any fun with it".

Okay, that's hyperbolic, but the point still stands that as of April 18, 2025 I have never used or seen a text editor with this specific functionality in it, and I think that's a real shame. Levitate's main gimmick will be this functionality (as well as my excuse to learn how to make a text editor from scratch).

I want Levitate to be a text editor filled with all sorts of unique, fun, and weird ideas.
